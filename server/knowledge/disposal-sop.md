# 园区异常处置 SOP（标准作业程序）

## 垃圾分类违规

- 判定要点：垃圾桶旁散落杂物、垃圾未入桶、分类投放错误
- 处置步骤：
  1. 拍照取证（近景 + 全景各一张，含位置参照物）
  2. 通知责任区保洁员 15 分钟内到场清理
  3. 清理后回访拍照，比对整改前后的画面
  4. 频发点位（周内 3 次以上）上报增设分类标识与督导岗
- 时限要求：一般违规 30 分钟内处置，大件垃圾 2 小时内清运
- 注意事项：涉及危险废弃物（灯管、电池）须单独收运，不得与普通垃圾混装

## 未熄烟头

- 判定要点：地面烟蒂、明火烟头、烟灰散落
- 处置步骤：
  1. 立即拍照取证并确认有无引燃风险（靠近纸屑、草坪属高风险）
  2. 高风险点位 5 分钟内到场熄灭清理，一般点位 30 分钟内
  3. 检查周边 3 米范围有无火情隐患
  4. 烟头高发区上报加装灭烟柱与禁烟标识
- 注意事项：草坪、绿化带内烟头按火灾隐患优先级处理，处置后 24 小时内复核一次

## 植被缺水

- 判定要点：草坪、灌木发黄，斑驳枯块，土壤干裂
- 处置步骤：
  1. 标记缺水区域边界，评估面积
  2. 48 小时内安排浇灌（选早晚时段，避开正午高温）
  3. 连续 3 天跟踪返绿情况，记录浇水量
  4. 反复缺水区域上报检修喷灌设施覆盖盲区
- 注意事项：夏季高温期判读标准放宽（轻度发黄即报），雨后 48 小时内不重复派单

## 货物堆放违规

- 判定要点：货物越线堆放、占用消防间距、超高堆垛
- 处置步骤：
  1. 拍照取证并核对堆放区域白线、黄线边界
  2. 联系库区责任人限时 2 小时内归位
  3. 逾期未整改的上报园区管理办，开具书面整改通知
  4. 整改后拍照归档，纳入责任区月度考核
- 注意事项：占用消防通道或消防设施的按最高优先级处理，同步通知安全员

## 通道占用

- 判定要点：疏散通道被堵、消防通道停车、安全出口堆物
- 处置步骤：
  1. 立即取证上报（最高优先级，5 分钟内响应）
  2. 现场确认堵占物归属，联系责任人即时清移
  3. 无法即时清移的设置临时警示并报安全负责人
  4. 处置完毕后无人机复核确认通道恢复畅通
- 注意事项：安全出口占用无论大小一律当日清零，严禁过夜

## 无人机复核

- 判定要点：地面初判异常需要二次确认时发起
- 处置步骤：
  1. 待复核异常由无人机 8 米高度悬停俯拍
  2. 俯拍帧与地面帧交叉比对，一致则状态转为已复核确认
  3. 复核不一致时改判或退回重查，备注差异点
- 注意事项：室内场景无无人机复核，直接进入人工确认
