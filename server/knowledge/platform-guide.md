# 智巡平台操作指南

## 巡查方式

- 快速巡逻：全园快速过一遍，适合日常例行检查
- 定点详查：对指定分区逐一细查，适合重点区域或复查
- 环视检查：环绕式巡查，适合广场、开阔区域

## 工单状态

- pending（未处理）：异常已确认，待派单
- processing（处理中）：已派单，处置进行中
- resolved（已处置完成）：处置完毕归档
- 支持重开：已处置的工单可重新打开返工，全程留痕

## 报告导出

- PDF 报告包含：场景信息、异常详情表（类型、位置、把握程度、证据）、处置进度统计
- 导出后可直接归档或移交物业跟进

## 模型配置

- 支持任意 OpenAI 兼容多模态接口
- 配置方式：AI 识别中心 → 模型配置，填写接口地址、API Key、模型名，保存前自动试连校验
- Key 仅保存在本机 server/config.local.json，不进代码库

## 设备接入

- 真机模式通过 WebSocket 协议对接（默认端口 9601）
- 支持急停：任务进行中随时可停止设备任务
- 模拟设备：server/sim_device.py 可本地联调

## AI 助手小巡

- 支持指令：发起巡逻（全园或分区）、切换场景与数据源、查询异常统计、标记处置完成、导出报告、呼叫无人机复核
- 后端不可用时自动降级为本地规则模式，指令仍可执行

## 思考链与语音

- 思考链：对话时按「检索知识库 → 组织回复 → 执行动作」三步实时展示，步骤完成后置灰勾选
- 语音输入：点麦克风或说唤醒词「小巡」开始说话，识别终稿后自动发送
- 语音播报：可在助手面板底部开关，较长回答会截断播报，避免长时间朗读
- 兼容性：浏览器不支持语音能力时，相关入口自动隐藏，不影响文字对话

## MCP 工具接入

- 作用：让 Claude、Cursor、TeleAgent 等标准 MCP 客户端直接查询园区状态、下发巡检指令
- 启动：后端启动后运行 server/mcp_server.py，默认监听 127.0.0.1:8790
- 可用工具：园区状态查询、异常清单、发起巡检、处置动作、知识问答、照片识别共六项
- 安全边界：默认仅本机可连，动作同样经过白名单校验，与页面操作共用同一动作链

## 巡检频次建议

- 日常例行：每日早晚各一次快速巡逻，覆盖全部主干路线
- 重点区域：垃圾房、食堂周边、施工围挡内每日两次定点详查
- 高风险项：消防通道与安全出口纳入每轮必查，发现即处置不留过夜
- 周度复盘：每周导出一次报告，结合工单统计评估责任区改善情况

## 报告字段与归档

- 报告结构：场景与时间信息、异常详情表、处置进度统计、证据索引
- 异常详情表包含：类型、位置（参照物 + 坐标）、把握程度、复核状态、工单状态
- 归档要求：按「园区-日期-轮次」命名保存，作为物业考核与合规检查依据
- 离线能力：报告由后端本地生成，不依赖外部服务，断网环境同样可导出
