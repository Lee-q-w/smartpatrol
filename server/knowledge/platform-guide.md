# 智巡平台操作指南

## 巡查方式

- 快速巡逻：全园快速过一遍，适合日常例行检查
- 定点详查：对指定分区逐一细查，适合重点区域或复查
- 环视检查：环绕式巡查，适合广场、开阔区域

## 工单状态

- pending（未处理）：异常已确认，待派单
- processing（处理中）：已派单，处置进行中
- resolved（已处置完成）：处置完毕归档
- 支持重开：已处置的工单可重新打开返工，全程留痕

## 报告导出

- PDF 报告包含：场景信息、异常详情表（类型、位置、把握程度、证据）、处置进度统计
- 导出后可直接归档或移交物业跟进

## 模型配置

- 支持任意 OpenAI 兼容多模态接口
- 配置方式：AI 识别中心 → 模型配置，填写接口地址、API Key、模型名，保存前自动试连校验
- Key 仅保存在本机 server/config.local.json，不进代码库

## 设备接入

- 真机模式通过 WebSocket 协议对接（默认端口 9601）
- 支持急停：任务进行中随时可停止设备任务
- 模拟设备：server/sim_device.py 可本地联调

## AI 助手小巡

- 支持指令：发起巡逻（全园或分区）、切换场景与数据源、查询异常统计、标记处置完成、导出报告、呼叫无人机复核
- 后端不可用时自动降级为本地规则模式，指令仍可执行
