# 智巡 SmartPatrol 现场演示手册

> 用途：省赛/国赛现场演示的操作手册与应急预案。核心原则：**前端核心功能（仿真/回放/工单/工作台）不依赖后端与外网，断网也全流程可演**；AI 识别与助手大模型对话是唯一需要网络与后端的增强项，已有降级方案。
> 演示流程与《演示视频分镜脚本》（段 C～G）一致，现场按本文顺序走即可。

## 二、标准演示流程（约 6 分钟）

### 1. 门户首页（30s）
- 开屏页自动播放（可点击跳过）→ 问候条、四大模块入口、状态概览、最新情报流。
- **台词点**：发现 → 处置 → 报告全闭环；虚实结合三数据源。

### 2. 一键全面体检 + 实时巡检（90s）
- 首页点「▶ 一键全面体检」→ 命令流实时汇报 → 异常标注上地图。
- 打开一条异常的**证据详情**：近景照片 + 无人机俯拍复核帧 + 把握程度 + 复核状态。
- **台词点**：AI 识别异常、证据链可追溯。

### 3. 工单闭环 + 报告导出（90s）
- 异常派单 → 处理中 → 处置完成；演示一次**重开返工**（体现留痕）。
- 「导出 PDF 报告」→ 打开 PDF 看**异常详情 + 处置进度**。
- **台词点**：报告含处置闭环数据，可直接移交物业。

### 4. 地图工作台（60s）
- 拖拽自建分区/设备/停靠点/路线 → 保存 → 回实时巡检页用自建场地跑一轮。
- **台词点**：任意场地可建图，适配真实园区。

### 5. AI 识别中心（90s）
- 上传演示照片（`演示素材/垃圾演示照片.jpg` 或烟头照片）→ 识别 → **回填到当前场景**。
- **台词点**：真图识别（虚→实）；Key 本机保存不出网。

### 6. AI 助手「小巡」（60s）
- 语音/输入：「详查西南分区」「现在有什么异常」「导出报告」。
- **台词点**：动作白名单安全执行；断网自动降级离线规则模式（可现场拔网线演示，见预案 A）。

### 7. 值守大屏（30s）
- 全屏指挥中心：统计卡、语义染色情报流、时钟。
- 收尾回首页。

## 三、应急预案

### 预案 A · 现场断网
| 演示项 | 影响 | 应对 |
|---|---|---|
| 仿真巡逻 / 工单 / 工作台 / 大屏 / 回放 | **无影响**（前端内置引擎） | 照常演示 |
| AI 识别中心识别 | 无后端+无外网则失败 | 改讲降级设计：现场拔网线演示助手自动切「离线规则模式」（面板副标题变橙色），播放演示视频中的 AI 识别片段（段 G）补证 |
| AI 助手大模型对话 | 自动降级 | 用离线规则模式继续演示（指令照常执行） |

**话术**：AI 能力设计为"可解释、可控、可降级"，断网正是展示架构韧性的机会——核心流程照转，AI 恢复即接入。

### 预案 B · 后端未启动 / 崩溃
1. 重新启动：`cd server && uv run python main.py`；
2. 起不来（如端口占用）：`netstat -ano | findstr 8788` 找到 PID → `taskkill /PID <pid> /F`；
3. 仍不行：前端功能不受影响，AI 项按预案 A 降级演示。

### 预案 C · 演示机故障
1. **浏览器白屏/卡死**：刷新页面（Ctrl+R）；开屏页最多 2.4s 自动过；
2. **整机故障**：换备用机，`pnpm install`（node_modules 已随 U盘备一份可解压直用）→ `pnpm dev`；
3. **彻底无法起服务**：播放演示视频（含完整功能链路 + AI 真实识别记录），配合答辩预案讲架构。

### 预案 D · 评审临时要求（常见）
- 「看看测试」：打开 `docs/test-report.md`（20 组测试矩阵）+ GitHub 仓库 README（CI 徽章绿色）；
- 「看看代码」：推荐顺序 `core/protocol.js`（统一协议）→ `adapters/SimAdapter.js`（引擎）→ `App.vue`（主视图）；
- 「看看文档」：`docs/` 下设备协议、测试报告、技术文档 PDF、作品介绍 PDF 齐全。

## 四、故障重启速查表

| 症状 | 原因 | 处置 |
|---|---|---|
| 页面 5199 打不开 | dev 服务未起/端口被占 | `pnpm dev`（strictPort 固定 5199）；占用则查 PID 强杀后重启 |
| AI 中心显示"在线静态演示" | 后端 8788 未启动 | 启动后端；页面会自动探测恢复 |
| 助手面板副标题橙色"离线规则模式" | 后端不可达（非故障） | 属降级设计；启动后端后自动切回"大模型驱动" |
| 识别报 503 / "未配置模型" | 模型 Key 未配置 | 「AI 识别中心 → 模型配置」填 Key 保存（自动试连） |
| PDF 导出失败 | 后端未启动或 8788 不可达 | 启动后端；导出走本地 ReportLab，无需外网 |
| 真机模式连接失败 | 9601 设备服务未起 | `cd server && uv run python sim_device.py`（模拟设备） |
| 构建报错 | 依赖不完整 | 删 `node_modules` 后 `pnpm install --frozen-lockfile` |
