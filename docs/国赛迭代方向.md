# 智巡 SmartPatrol 国赛迭代方向清单

> 用途：若晋级国赛，作品需要在省赛基础上"更进一步"。本清单对齐技术文档「八、总结与展望」的四个埋点方向，展开为可执行的迭代项，每项给出目标、技术路径（全部基于现有架构扩展，不推翻重来）与验收标准。
> 优先级建议：P1（多设备接入）> P2（工单通知）> P3（移动端）> P4（多园区），工作量与演示增益综合排序。

---

## P1 · 多设备类型接入（地空协同巡检）

**目标**：从"巡逻车单设备"扩展为"巡逻车 + 摄像头 + 无人机"多设备协同，形成地空一体的巡检网络。

**技术路径**（现有架构的直接延伸）：
1. 统一协议（`core/protocol.js`）扩展设备角色字段与定点拍照命令——协议层改动，三适配器同步受益；
2. 新增 `adapters/DroneAdapter.js`：无人机巡航适配器（复用真机 WebSocket 协议，增加航点任务与俯拍事件）；
3. 地图渲染：无人机航迹与俯拍覆盖区可视化（Canvas 2.5D 已支持多图层，增量开发）；
4. 复核链路升级：异常复核从"模拟无人机帧"升级为真实无人机俯拍回传（证据链里已有的 `droneB64` 字段直接承接）。

**验收标准**：一套场景里巡逻车地面巡查 + 无人机空中复核协同完成一轮巡检；证据详情同时展示地空两路证据帧。

**演示增益**：★★★★★（"地空协同"是强视觉点，直接回应"和摄像头方案差异"的追问）

---

## P2 · 工单通知集成（处置主动找人）

**目标**：异常派单后实时推送处置人，把"人盯平台"变成"平台找人"。

**技术路径**：
1. 后端新增通知模块：FastAPI 事件钩子监听工单状态变更（pending/processing/resolved）；
2. 对接企业微信 / 钉钉群机器人 webhook（HTTP POST，无需企业认证即可群机器人演示）；
3. 通知模板：异常类型 / 位置 / 把握程度 / 证据缩略图 / 平台跳转链接；
4. 前端「模型配置」旁增加「通知配置」（webhook 地址），与现有配置体系一致（本机保存、试连校验）。

**验收标准**：派单后 5 秒内企业微信群收到卡片消息；处置完成状态同步推送。

**演示增益**：★★★★（打通"发现→找人→处置"最后一环，答辩讲业务闭环最有说服力）

---

## P3 · 移动端值守（手机派单处置）

**目标**：响应式布局延伸到手机端，管理者手机即可完成查看与派单处置。

**技术路径**：
1. 现有布局断言体系（1600×900 / 1280×800）扩展 390×844 移动档；
2. 首页/巡检视图/工单面板做窄屏适配（CSS 网格降级，模式参考现有 1180px 断点）；
3. 值守大屏适配竖屏"简报模式"（统计卡 + 情报流）；
4. Canvas 地图支持触摸缩放/平移。

**验收标准**：手机浏览器完成"看异常 → 派单 → 标记处置"全流程，布局断言移动档全过。

**演示增益**：★★★（现场掏手机操作，互动感强；工程量相对大，排 P3）

---

## P4 · 多园区集中管理（场景库云端化）

**目标**：一个账号管理多个园区站点，支撑跨园区运营。

**技术路径**：
1. 场景数据模型已支持多场景切换（园区/仓库/自建），先做**场景导入导出**（JSON 文件，零后端即可用）；
2. 后端增加场景库接口（上传/列表/克隆），自建场景一键同步；
3. 站点切换器升级为"园区列表 + 汇总概览"；
4. （远期）账号体系与权限：评审演示可用"演示模式"虚拟账号，不做真实注册登录。

**验收标准**：两个园区各自巡检，概览页汇总展示全网异常与处置率。

**演示增益**：★★★（从"单平台"到"平台群"的格局升级，商业化叙事的支点）
